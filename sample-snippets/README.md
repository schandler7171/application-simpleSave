# Sample Snippets

Ready-made CSV files you can import straight into simpleSave to see it in
action (or just to have a handy reference library from day one).

Each row's `title` is a one-sentence description of what the snippet does;
`body` is the actual command or code.

| File | Covers |
| --- | --- |
| `bash-terminal-commands.csv` | Everyday Bash / shell terminal commands (files, processes, archives, networking) |
| `html-snippets.csv` | Common HTML tags and page structures |
| `javascript-snippets.csv` | Core JavaScript syntax and DOM/fetch patterns |
| `css-snippets.csv` | Layout, spacing, color, and responsive CSS patterns |
| `python-snippets.csv` | Everyday Python syntax, file I/O, and scripting patterns |

## Importing

Open simpleSave, click **Import**, and pick one of these files. Each one
creates its own folder (e.g. "Sample Snippets/Bash Terminal") so they stay
organized and separate from your own snippets. Import as many, or as few,
of these files as you like — running an import again just adds another
copy, so remove a folder first if you want to re-import cleanly.
